# Licence texts

Keep the full text of every licence that applies to a shipped asset here.

- `CC0-1.0.txt` — Creative Commons Zero 1.0 Universal
- `CC-BY-4.0.txt` — Creative Commons Attribution 4.0 International

## Adding a licence

- Do not edit the licence text.
- Name the file after the licence and version, e.g. `CC-BY-3.0.txt`.
- If a pack ships its own licence file, keep it as
  `<pack-name>-LICENSE.txt` as well.
- Record the matching asset, author and source URL in `CREDITS.md`.

CC0 does not require attribution, but we still credit every asset. CC-BY
requires attribution; include the author, licence link, source and any changes
in `CREDITS.md` and in the in-game credits screen when it exists.
